# Task Reminder

Десктопное приложение-напоминалка для Windows 10 Pro. Хранит задачи и напоминания, отправляет уведомления в Telegram, работает в системном трее.

## 📖 Описание

Task Reminder помогает не забывать дела. Задачи группируются по проектам, имеют срок выполнения, вложения и статус. Когда приходит срок, приложение показывает всплывающее окно и отправляет сообщение в Telegram.

## ⚙️ Требования

- Операционная система: Windows 10 Pro
- Python 3.12.10
- Подключение к интернету для отправки Telegram-уведомлений
- Учетная запись Telegram для настройки бота

## 🤖 Настройка Telegram

1. Создайте бота:
   - Откройте Telegram и найдите @BotFather.
   - Отправьте команду `/newbot` и следуйте инструкциям.
   - Скопируйте полученный токен, например `123456789:ABCdefGHIjklMNOpqrsTUVwxyz`.

2. Узнайте свой `chat_id`:
   - Найдите в Telegram @userinfobot и нажмите Start.
   - Бот пришлет ваш идентификатор, например `123456789`.

3. Обязательно отправьте созданному боту команду `/start`, иначе он не сможет писать вам.

При первом запуске приложения появится окно настройки Telegram, куда нужно вставить токен и `chat_id`.

## ▶️ Первый запуск

```powershell
python main.py
```

После ввода настроек Telegram откроется главное окно. Добавьте проект, затем добавьте задачу с датой и временем.

## 🔄 Автозагрузка

- Откройте приложение и найдите значок в системном трее.
- Правый клик по значку → откройте настройки автозагрузки (или используйте соответствующую галочку в интерфейсе трея).
- Включите автозагрузку — приложение будет запускаться вместе с Windows.

## 📁 Структура проекта

- `main.py` — точка входа и запуск всех потоков.
- `db.py` — работа с SQLite: проекты, задачи, вложения, настройки.
- `gui.py` — главное окно Tkinter.
- `notification_manager.py` — фоновая проверка сроков и всплывающие уведомления.
- `telegram_bot.py` — Telegram-бот с inline-кнопками.
- `system_tray.py` — иконка в трее и автозагрузка.
- `attachment_manager.py` — работа с прикрепленными файлами.
- `ui/datetime_picker.py` — календарь и выбор времени.
- `tests/` — unit-тесты.

## 🐛 Troubleshooting

### Не приходят уведомления в Telegram

- Убедитесь, что компьютер подключен к интернету.
- Проверьте, что вы написали боту `/start`.
- Проверьте правильность токена и `chat_id`.
- Время задачи хранится в UTC, а отображается в локальном; убедитесь, что дата и время выбраны корректно.

### Календарь отображается не на русском

- Убедитесь, что установлен пакет `babel==2.18.0`.
- При использовании venv активируйте его перед запуском.

### Ошибка `TaskLimitExceeded`

- В одном проекте может быть не более 10 задач.
- Удалите старую задачу или создайте новый проект.

### Иконка в трее не появляется

- Убедитесь, что установлены `pystray==0.19.5` и `Pillow==13.0.0`.
- На Windows иконка может скрываться в меню переполнения системного трея.

### Нужно сменить токен или chat_id

- Закройте приложение.
- Удалите файл `tasks.db` и папку `attachments`, либо отредактируйте таблицу `config` через DB Browser for SQLite.
- При следующем запуске приложение снова запросит настройки Telegram.

### Вложения не открываются

- Убедитесь, что файл находится в папке `attachments`.
- Проверьте, что для типа файла установлена программа по умолчанию в Windows.
